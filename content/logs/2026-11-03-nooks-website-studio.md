The first product on the foundation is an AI website studio.

- Sites are generated into immutable bundles and hosted on **Dynamic Workers**, with site data in **D1**.
- A visual editor (**Puck**) lets you change the generated page directly, with a live draft preview.
- Each site gets its own chat agent running in a **Durable Object**, so conversations stay with the site.

Conversational editing landed the same day: describe a change, watch it generate, and see the preview update as it goes.
